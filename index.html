EPUB → Markdown

Converts .epub books to .md, split into parts of up to 240 KB each. Chapter names become main headings (#), the book's own headings are kept underneath them (##, ###…). Whole chapters are packed into each part; a chapter is only cut if it is bigger than the limit on its own. Works offline in your browser — files are never uploaded.

Max size per file KB Measured in UTF-8 bytes (1 KB = 1000 bytes; Hindi letters take 3 bytes each).

Tip: if a chapter name appears twice or is missing, the EPUB's table of contents is unusual — try switching the first option off.
